動画で紹介した5つのプラグインについて、「何をするものか」「向いている人」「導入の流れ」「注意点」をまとめました。数字が出てくる箇所は、それがプロジェクト側の公称値なのかを必ず明記しています。宣伝文句の数字を、そのまま鵜呑みにしないためのガイドでもあります。

BEFORE YOU START

始める前の前提

  • このガイドは、AIコーディングツール「Claude Code」がパソコンに入っている前提で書いています。まだの場合は、先にClaude Code自体の導入が必要です。
  • プラグインの追加は、Claude Codeの中で /plugin install プラグイン名@マーケットプレイス名 のように打つのが基本形です。マーケットプレイス（配布元のカタログ）が未登録の場合は、先に /plugin marketplace add 配布元 を実行します。
  • 各プラグインの仕様・料金・無料枠の条件は変わることがあります。導入前に、各プラグインの公式ページで最新の条件を確認してください。
  • 順位は動画と同じ並びです。「便利さ」の絶対評価ではなく、「小さな会社がAI導入を進めるうえでの効きどころ」の順に並べています。
THE FIVE

プラグイン5選（5位→1位）

第5位

Claude Security

提供：Anthropic（公式）／セキュリティスキャナ

何をするものか

Claude Codeのセッションの中で動く、脆弱性（セキュリティ上の弱点）のスキャナです。複数のAIエージェントが役割分担して、コード全体の構成を把握し、脅威モデル（どこを狙われうるか）を作り、弱点を探し、見つけた指摘を別のエージェントが独立に検証してからレポートにまとめます。対象はリポジトリ全体でも、ブランチやプルリクエストの差分だけでも指定できます。確認した指摘については、修正パッチの提案まで出せます（パッチは自動では適用されません）。

向いている人

自社でWebサービスや業務システムのコードを持っていて、「専門業者に頼む前に、まず一次点検をしたい」という人。とくに、顧客情報を扱うシステムを運用している小さな会社に向きます。

導入の流れ

  1. ターミナルで claude と打ってClaude Codeを起動する
  2. 公式マーケットプレイスからインストールする
  3. /claude-security と打ってメニューを開き、「コードベースのスキャン」「変更分（差分）のスキャン」「パッチの提案」のいずれかを選ぶ
  4. レポートを確認し、採用する指摘だけパッチを取り込む
/plugin install claude-security@claude-plugins-official
/claude-security

注意点

  • 実行には、Claudeの有料プラン、APIアクセス、または対応する外部プロバイダのいずれかが必要です。あわせて、パソコンにPython 3.9以上が入っている必要があります。
  • スキャンはトークン（利用量）を多く消費し、終わるまでClaude Codeを開いたままにしておく必要があります。
  • スキャン結果は実行ごとに揺れる（非決定的な）性質があります。既存の静的解析ツールや、専門家によるレビューの代わりにはなりません。公式ドキュメント自体が「併用するもの」と位置づけています。
  • 同名の「Claude Security」という法人向けの管理サービス（Enterpriseプラン向け）とは別物です。このガイドで扱うのは、Claude Codeのプラグイン版です。

公式ドキュメント：code.claude.com/docs/en/claude-security

第4位

Claude Code Setup

提供：Anthropic（公式）／セットアップ提案

何をするものか

プロジェクトのコードベースを読み取り、そのプロジェクトに合った「自動化の次の一手」を提案してくれるプラグインです。提案の対象は、MCPサーバー（外部連携）、スキル、フック（自動実行の仕掛け）、サブエージェント、スラッシュコマンドの5分野で、各分野の上位1〜2件に絞って出てきます。中身は提案専用のスキルで、読み取り専用——ファイルを勝手に作ったり書き換えたりはしません。

向いている人

Claude Codeを入れたものの、「設定や拡張を何から手をつければいいか分からない」という人。逆に、入れすぎて散らかったプロジェクトの棚卸しにも使えます。

導入の流れ

  1. Claude Codeを起動し、公式マーケットプレイスからインストールする
  2. 対象のプロジェクトフォルダでClaude Codeを開く
  3. 「recommend automations for this project（このプロジェクトに合う自動化を提案して）」のように、普通の言葉で頼む
  4. 出てきた提案のうち、納得できたものだけを自分で導入する
/plugin install claude-code-setup@claude-plugins-official

注意点

  • あくまで「提案」までです。実際の導入は、内容を確認してから自分で行います。
  • 提案はコードベースの中身から判断されるため、空のフォルダや実体のないプロジェクトでは材料がなく、的確な提案は出ません。
  • 提案されたものを全部入れる必要はありません。入れすぎは、かえって動作を重くします。

公式ページ（Anthropic公式リポジトリ内）：github.com/anthropics/claude-plugins-official（plugins/claude-code-setup）

第3位

Caveman

提供：オープンソース（Julius Brussee氏）／出力トークン削減

何をするものか

AIの回答の「余分」を削るプラグインです。前置き、丁寧すぎる言い回し、繰り返しの要約などを落とし、技術的な中身はそのままに、短い断片的な文体で答えさせます。これにより、AIが生成する側のトークン（出力トークン）が減ります。削減幅は出力トークン約65%＝プロジェクト側が公表しているベンチマークの平均値（公称）で、効果を測るための /caveman-stats という確認用コマンドも用意されています。簡潔さの強さは段階で選べます。

向いている人

Claude Codeを毎日使い、利用枠の消費やコストが気になる人。長い説明文より、要点だけを速く受け取りたい人に向きます。

導入の流れ

  1. Claude Codeで、配布元のマーケットプレイスを登録する
  2. プラグインをインストールする
  3. /caveman と打って有効化する（強さの指定もここで行う）
  4. しばらく使ってから /caveman-stats で、実際の削減量を確認する
/plugin marketplace add JuliusBrussee/caveman
/plugin install caveman@caveman
/caveman

注意点

  • 減るのは出力トークンだけです。読み込ませる側の入力トークンや、AIの思考（推論）にかかるトークンは減りません。「全体のコストが65%減る」という意味ではありません。
  • 約65%という数字はプロジェクト公称のベンチマーク値です。第三者による検証では、実際の削減幅はもっと小さいという報告もあります。自分の環境で /caveman-stats を見て判断してください。
  • 回答が極端に簡潔な文体になります。お客様向けの文章づくりや、丁寧な説明が必要な場面には向きません。
  • コマンドライン版のツールには、利用状況の送信（テレメトリ）が既定で有効になっている場合があると報告されています。気になる場合は、導入時に公式READMEで無効化の方法を確認してください。

公式リポジトリ：github.com/JuliusBrussee/caveman

第2位

Superpowers

提供：オープンソース（Jesse Vincent氏／Prime Radiant）／進め方の型

何をするものか

AIの「進め方」そのものを型にはめるスキル集です。いきなり作り始めさせず、まずブレインストーミングで「何を・なぜ作るか」を詰めて仕様を承認し、それを2〜5分単位の小さなタスクの計画に落とし、テストを先に書く進め方（TDD）で実装し、タスクごとにレビューを挟む——という順序を踏ませます。「言ったのと違うものが、大きく出来上がっていた」という事故を防ぐための仕組みです。

向いている人

AIに任せたら仕様と違うものができた、作りすぎた、という経験がある人。複数ステップにわたる開発や、失敗したときの手戻りが大きい仕事を任せたい人に向きます。

導入の流れ

  1. Claude Codeで、公式マーケットプレイスからインストールする
  2. 新しいセッションで、作りたいものを普通に頼む
  3. 最初にコードではなく、ブレインストーミング（仕様の確認）が始まるので、質問に答えて仕様を承認する
  4. 計画が提示されるので確認し、あとは計画に沿って実装とレビューが進む
/plugin install superpowers@claude-plugins-official

注意点

  • 手順が増える分、所要時間とトークン消費は増えます（第三者の検証では、素のClaude Codeと比べて約1.4倍のコストだったという報告があります）。
  • 小さな修正や、すぐ終わる作業には過剰です。使い分けが前提になります。
  • 途中で仕様や計画の確認が何度も入ります。「丸投げして放置」とは相性がよくありません。

公式リポジトリ：github.com/obra/superpowers

第1位

OmniRoute

提供：オープンソース（MITライセンス）／AIゲートウェイ

何をするものか

自分のパソコンで動かす「AIの窓口（一元化ゲートウェイ）」です。300以上のAIプロバイダ（提供会社）に対応し、各社のアカウントを登録しておくと、Claude Codeなどのツールからのリクエストを1つの窓口で受け止め、利用枠が残っているプロバイダへ振り分けます。1社の上限に達したら、次へ自動で切り替わるため、「上限に当たって作業が止まる」を避けられます。あわせて、送る内容を圧縮してトークン消費を抑える機能も備えています。

向いている人

1社の利用上限に当たって作業が止まることが多い人。各社が用意している無料枠を、組み合わせて使いたい人に向きます。

導入の流れ

  1. ターミナルでOmniRouteをインストールする（Node.jsが必要です）
  2. omniroute serve で起動し、管理画面（ダッシュボード）をブラウザで開く
  3. 管理画面の「Providers」から、使いたい各プロバイダのアカウントを接続する
  4. Claude Code側の接続先をOmniRouteに向ける設定を行い、モデルは自動選択（auto）にする
npm install -g omniroute
omniroute serve
「月約15億トークン」という数字の読み方（必ずお読みください）
OmniRouteが公表している無料トークンの量（月約15億トークン規模）は、各プロバイダの無料枠をすべて合計した総量（プロジェクト公称）です。1社からその量がもらえるわけではありません。各社の無料枠には、それぞれ回数や速度の上限があり、実際に使える量は「どの会社の、どの無料枠を登録したか」で決まります。無料枠の内容は各社の都合で予告なく変わることもあります。「合計すれば大きい」という話と、「自分が使える量」は別物として理解してください。

注意点

  • 無料枠はOmniRouteが配っているものではありません。各プロバイダの無料アカウントを、自分で用意して接続する仕組みです。
  • 無料プロバイダに送った内容は、そのプロバイダ側に渡ります。顧客情報・個人情報・機密のコードは、無料枠の経路には流さないでください。
  • 上限に達したときの切り替え先が無料モデルの場合、回答の品質が落ちることがあります。切り替え先は、信頼できるモデルに絞って設定するのが安全です。
  • 導入にはターミナル操作が必要です。コマンド操作に不慣れな場合は、無理に進めず、慣れた人に手伝ってもらうか、私たちの無料相談で進め方だけ聞いてください。

公式リポジトリ：github.com/diegosouzapw/OmniRoute

HOW TO CHOOSE

全部入れる必要はありません

プラグインは「入れた数」ではなく「自社の業務に効いたか」で判断するものです。目安として、困りごと別に優先順位をつけています。

  • 何から設定すればいいか分からない → まず Claude Code Setup（第4位）だけ入れて、提案を受ける
  • 作るたびに仕様とずれる → Superpowers（第2位）で進め方を型にはめる
  • 利用枠の消費が速い → Caveman（第3位）で出力を絞る。ただし効果は自分の環境で測ること
  • 上限に当たって止まる → OmniRoute（第1位）。ただし無料枠の数字の読み方に注意
  • 自社システムの安全性が心配 → Claude Security（第5位）で一次点検をする
